The Idea

Why Saturn?

Platforms like ChatGPT and Gemini are powerful but they felt impersonal. I wanted something with a sense of fun and a design that felt like mine. So I built Saturn, a space-themed AI search platform built on top of the Gemini API, designed and developed entirely from scratch in React.

Beyond the creative challenge, this was a learning project. Building Saturn gave me hands-on experience integrating an AI API, managing chat state in React, and thinking carefully about UI/UX for conversational interfaces.

What I Built

Features.

AI Search via Gemini

Integrated Google's Gemini API to power the search and conversational functionality, handling prompt construction and response parsing within React.

Chat History

Built a session-based chat history so users can scroll back through their conversation without losing context. A core UX need for any AI chat interface.

Space-Themed UI

Built a custom dark UI with a deep space palette, type hierarchy, and space-inspired component system that makes Saturn feel distinct from standard AI tools.

Activity-Based Recommendations

Saturn surfaces contextual recommendations based on prior queries, giving users a more personalized and discoverable experience than a standard search box.

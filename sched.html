The Project

What is Sched?

Built for my Processes of Object-Oriented Software Development course, Sched is a group project that tackles a real workplace pain point — building employee schedules. Managers spend hours manually reconciling availability. Sched automates that by letting employees submit their preferences and generating optimal schedules from there.

My responsibilities covered the UI mockup design and the MongoDB database architecture, giving me ownership of both how the product looks and how it stores its data.

My Contributions

What I did.

UI Design in Figma

Designed the full interface in Figma — from the schedule dashboard and employee profiles to the account creation flow — giving the dev team a clear visual spec to build from.

Database Architecture

Designed and managed the MongoDB schema to support employees, managers, availability windows, and generated schedules — ensuring the data model was flexible enough for future features.

Schedule Dashboard

Designed the primary view managers use to see generated schedules at a glance, with layouts that make shift patterns easy to read across the full work week.

Employee & Manager Profiles

Built out the profile system UX for both roles — each with different permissions and views — so the app could serve both sides of the scheduling equation from a single platform.

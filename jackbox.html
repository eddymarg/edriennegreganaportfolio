The Project

Where it started.

This was one of my very first coding projects, built for a KnightHacks presentation during the spring semester. Each team member contributed a mini-game to a shared Jackbox-style platform. My contribution: a fully playable, two-player Tic-Tac-Toe game built in Unity with C#.

It was a small project in scope, but an important one. It was where I first got comfortable working in a team environment, using version control, and shipping something real.

My Contributions

What I built.

Tic-Tac-Toe in Unity

Built a classic two-player Tic-Tac-Toe game in Unity using C# handling game state, turn logic, win/draw detection, and a restart flow all from scratch.

Shared Platform Integration

My game was integrated into the team's shared Jackbox-style landing page alongside games built by other team members, creating a cohesive multi-game hub.

Team Collaboration & Git

Used GitHub for version control across a multi-contributor project for the first time — coordinating commits, resolving merge conflicts, and shipping a working final product.

Live on itch.io

The project was published and playable on itch.io, making it one of my first deployed products. It's still live! a small but real milestone in my development journey.

The Project

What is Sproutfolio?

Developed for my Processes of Object-Oriented Software Development course, Sproutfolio is a contact management system with full CRUD functionality. The theme puts a playful spin on a standard data management platform however, the contacts are framed as plants you tend to.

My focus was on web design and frontend development: translating the concept into a clean, functional interface with thoughtful UX for creating, reading, updating, and deleting records.

What I Built

Features.

Full CRUD Operations

Users can create, view, update, and delete contacts. The full lifecycle of a record, implemented cleanly with vanilla JavaScript and a structured data model.

Search Functionality

A real-time search bar lets users filter contacts instantly without a page reload, making it easy to find the right entry even as the list grows.

Organizing Filters

Contacts can be sorted and filtered by category, keeping the list manageable and giving users more control over how they view their data.

UI Design

Designed the full interface; palette, typography, layout to reflect the plant theme while keeping the experience clean and intuitive for a data-focused app.
